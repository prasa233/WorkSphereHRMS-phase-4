WorkSphere HRMS --- Phase 4
Overview
Phase 4 enhances employee experience, internal workflows, and system
integrations.
Modules
- 21. Employee Onboarding: Assign checklist tasks and track
  progress.
- 22. Resignation & Exit: Submit resignations and manage
  approvals.
- 23. Announcements: HR/Admin can publish internal announcements.
- 24. Task Management: Assign employee tasks, set due dates, and
  track status.
- 25. Integrations: Email notifications, optional Google Calendar
  sync, and CSV/PDF exports.
- 26. Employee Feedback: Submit ratings and feedback; HR/Admin can
  review submissions.
- 27. Profile & Settings: Update profile, change password, and
  manage notification preferences.
Database
New tables: Onboarding, Resignations, Announcements, Tasks, and
Feedback.

Existing tables remain in use, including Users, Employees,
Attendance, Leaves, Payroll, Notifications, Shifts,
Performance, and Documents.
Security
- JWT authentication
- Role-based authorization and ownership checks
- Pydantic input validation
- Secure environment configuration
Deliverables
Onboarding, exit management, announcements, task tracking, integrations,
feedback, and profile/settings feat
